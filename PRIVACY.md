# Privacy Policy — Q-Sports-AI Backup OAuth

**Effective date:** November 20, 2026

## Operator and purpose
Q-Sports-AI Backup OAuth is operated by the owner of the Q-Sports-AI project for personal backup and recovery. It authorizes rclone on the owner's server to access the owner's Google Drive.

## Google user data
The application uses authorized Google Drive access to create, list, read, update, and remove files as required for the owner's encrypted Restic backup repository. It is intended solely for the operator's Google account.

## Use and storage
Restic encrypts backup payloads before uploading them to Google Drive. OAuth credentials and tokens are kept in the owner's private server configuration and are not published in this repository.

## Disclosure
The operator does not sell Google user data or share it with advertisers. Data is processed by Google Drive and the owner's hosting provider as necessary for the backup service.

## Retention and control
Backup files are retained in the owner's Google Drive until the owner deletes them. The owner can revoke access through Google Account security settings and delete backups directly.

## Contact
Contact the repository owner through GitHub for privacy inquiries.

## Updates
This policy may be updated if the backup workflow changes.
